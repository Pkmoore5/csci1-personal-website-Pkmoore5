# CSCI 1 Personal Website Project

Use the working examples in `index.html` as a guide. Search for **TODO** and complete each item.

## Required Work
- **About Me:** Replace `YOUR NAME` and add 2–3 sentences.
- **Education:** Reedley College is the example; add your previous school(s).
- **Current Courses:** CSCI 1 is the example; add your other current courses.
- **Interests:** Technology is the example; add at least three interests/hobbies.
- **Favorite Music:** Add a song title and a legal link. Do not upload copyrighted commercial music.
- **Favorite Video:** Replace `VIDEO_ID` with an appropriate YouTube video's ID.
- **Projects:** Scratch Project is the example; add other CSCI 1 work as the semester continues.
- **Image:** You may replace `images/profile-placeholder.svg` with an appropriate image. A personal photo is optional.

## Clone Your Repository and Open It in VS Code

1. Open your personal website repository on GitHub.
2. Click **Code** and copy the HTTPS repository address.
3. Open a terminal or Command Prompt.
4. Run:

```bash
git clone YOUR-REPOSITORY-URL
cd YOUR-REPOSITORY-NAME
code .
```

## Save Your Work to GitHub

After editing and testing your website:

```bash
git status
git add .
git commit -m "Update my personal website"
git push
```

Your basic workflow is:

**Edit → Save → Test → git status → git add → git commit → git push**

## Publish Your Website with GitHub Pages

After your instructor tells you the website is ready to publish:

1. Make sure your latest work has been committed and pushed.
2. Open your personal website repository on GitHub.
3. Click **Settings**.
4. Click **Pages** in the left menu.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select **main** as the branch and **/ (root)** as the folder.
7. Click **Save**.
8. Wait a few minutes for GitHub to publish the website.
9. Return to **Settings → Pages** to find your published website address.
10. Open the address and verify your website works.
11. Submit your published website URL in Canvas when instructed.

Keep `index.html` in the root of your repository for this setup.

## Privacy and Safety

Your published website may be publicly accessible. Do not include your home address, personal phone number, student ID, passwords, private documents, or other sensitive information.

A personal photograph is optional. You may use an appropriate avatar, illustration, or other image instead.

Never commit passwords, access tokens, or other secret information to GitHub.
